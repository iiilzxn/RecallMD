# RecallMD UI · 书房

整体方向：暖纸色阅读界面、带少量苔绿色强调的深色界面，以及适合长时间阅读的留白和文字层级。新视觉层集中在 `src/ui/workspace.css`，由 `src/main.tsx` 在基础样式之后加载。

## 页面变化

- 工作区：主要导航移到文件树上方；知识库选择、学习导航、文件操作和本地状态分组。主内容区采用独立的圆角纸面。
- 笔记：标题与路径分层，编辑/阅读采用明确的双按钮切换；调整阅读宽度、段落间距、代码块、引用和目录。标题旁的得分点标签沿用五字省略与全文提示。
- 复习：强化当前题目，区分“先试着回忆”和“对照与反馈”；显示本轮剩余小节与实际进度。收紧作答区，让首屏更容易看到提交按钮。四档评级卡片使用各自的语义颜色和快捷键标记。
- 统计：真实复习次数概览、今天/近 7 天/近 30 天的自评分布和可展开明细。数据仍来自现有统计接口，不推断记忆率。
- 设置：增加用途导航、三种主题的可视预览、开关样式，以及 Jev 配置状态。知识库、学习偏好、打分、复习内容、备份分别成组。
- 启动页：双栏欢迎页，左侧介绍记录—回忆—巩固的流程，右侧提供知识库选择和最近使用入口。
- 通用界面：统一按钮、对话框、输入框、反馈消息和空态；Mermaid 从当前主题变量取色，和正文保持一致。

同时修正展示细节：切换页面和进入下一题时回到顶部；首次学习提交后，用服务返回的新配额刷新界面。

## 验证

- `pnpm typecheck` 通过。
- `pnpm test`：22 个测试文件，200 项通过，2 项既有测试跳过。
- `pnpm build` 通过；原有大块体积提示仍存在。
- 浏览器检查了启动页、编辑/阅读切换、标题得分点弹窗、复习提交与进度、统计周期切换、设置分组和主题切换。
- 窗口宽度检查覆盖默认桌面、820、600 和 390 像素；笔记和设置未出现文档级横向溢出。窄窗口将文件导航移到上方、文档目录移到正文下方。
- 检查了浅色与跟随系统的深色，以及 Mermaid 流程图文字和配色。
- 弹窗关闭后焦点返回触发按钮；保留原有原生对话框与快捷键保护。

浏览器预览使用开发示例数据，不访问真实笔记、不调用 Jev。原生存储、备份、模型调用和 FSRS 算法没有在本轮重写。

## 预览入口

运行 `pnpm dev --host 127.0.0.1`，打开以下入口：

- 启动页：`http://127.0.0.1:5173/`
- 阅读页：`http://127.0.0.1:5173/?demo=reading`
- 复习页：`http://127.0.0.1:5173/?demo=review&jev=1`（固定模拟评分）
- 统计页：`http://127.0.0.1:5173/?demo=stats`
- 设置页：`http://127.0.0.1:5173/?demo=settings`

开发示例脚本只在 Vite 开发服务中注入，生产构建不包含示例宿主。
