## 这是什么

Windows 本地 Markdown 编辑器 + FSRS 间隔复习桌面应用。笔记就是普通 `.md` 文件，复习块由标题直属正文自动划分（§8.1），学习记录保存在知识库内 `.recallmd/` 目录。

## 功能一览

- **知识库**：打开任意本地文件夹作为知识库（独占锁）；目录树 / 新建 / 重命名 / 移动 / 回收站（不自动清空）；按文件名过滤（Ctrl+P）
- **安全编辑器**：八步保存协议（M1）；自动保存 + 崩溃草稿恢复；冲突三选一（磁盘版 / 本地覆盖留备份 / 另存）；UTF-8 / LF / CRLF / BOM 保全；Markdown 语法高亮
- **块引擎**（M3）：保存时自动为复习块插入 `<!-- recall:block:UUID -->` 锚点；锚点身份修复（重复 / 错位 / 缺失）
- **复习**（M5/M6）：FSRS 调度（request_retention 0.90，冻结参数）；先回忆后揭示；四档自评（Again/Hard/Good/Easy）；回忆提示；新内容日配额（默认 20）；跳过 / 暂停 / 永久排除；正文变更时"沿用进度或重新学习"
- **可靠性**（M4/M7）：外部编辑器 / Git 改动的自动检测与重扫；文件移动后学习记录自动跟随（按内容采纳）；SQLite 日备轮换 + 完整备份 / 恢复
- **统计**：评分次数（今天 / 7 天 / 30 天）、四档分布、当前状态

## 安装与升级

1. 双击安装包（每用户安装，无需管理员；SmartScreen 会提示"未知发布者"——更多信息 → 仍要运行）
2. 升级：直接安装新版本覆盖
3. 卸载：控制面板 / 设置 → 应用。**卸载不动知识库**——笔记与学习记录都在你选择的文件夹里

## 数据与备份

- 知识库内 `.recallmd/`：学习记录数据库、恢复材料、操作日志、回收站
- 设置页支持：立即备份数据库（每日自动）/ 完整备份（含正文）到任意目录 / 从完整备份恢复
- 建议：重要知识库定期"完整备份"到异地位置

## 已知限制（第一版）

- 仅 Windows 10/11 x64；仅本机固定磁盘 NTFS 分区的文件夹可作为知识库
- 不支持多实例同时打开同一知识库（独占锁，第二窗口会明确报错）
- 冲突不做三方自动合并（提供三选一 + 手动合并流程）
- 文件级视图的按文件复习模式为发布后候选（当前是全库单队列）
