## 相对 v0.1.0 的变化

### 新增

- **只读 Markdown 预览**（设计 §207）：编辑器顶栏新增眼睛按钮 / `Ctrl+E`，整个编辑面板切换为渲染视图；再点返回编辑。预览与块引擎使用同一 Markdown 方言（remark + GFM + frontmatter）；ID 锚点注释与 frontmatter 不显示；原始 HTML 一律不执行（§161 受控渲染）。预览含未保存修改，保存插锚 / 外部重载后自动刷新。≥5 MiB 或 5 万行的大文件禁用预览（§1014）
- **右侧目录（TOC）**：编辑态与预览态常驻右侧；层级缩进显示，点击跳转（预览滚动到标题、编辑态光标定位）；目录来自真实 AST 解析，代码围栏内的 `#` 不会误入；编辑态输入空闲 700ms 防抖刷新
- **复习正文渲染**：复习页揭示后的答案由原始 Markdown 文本改为受控渲染（与预览同模块，§207 要求复用）
- **链接策略**（§161）：文内相对 `.md` 链接在应用内打开；外链只提示、不在应用内导航；`javascript:` 等协议渲染为不可点文本；图片显示占位框（默认无任何自动网络请求）

### 修复

- **最近列表首次无法持久化**：应用配置目录不存在时写入失败（os error 3），导致「最近的知识库」从未生效；现在写入前自动创建目录

### 已知取舍

- 预览态图片一律占位框（本地图片显示需启用 asset protocol，后续版本）；文内 `#锚点` 跳转暂不可用
- 编辑态目录在输入停顿前最多滞后约 700ms，跳转偏移随之略有偏差
- 外链需手动复制到浏览器打开（未集成 opener 插件）

## 安装与升级

同 v0.1.0：直接安装覆盖；卸载不动知识库（`.recallmd/` 与 `%APPDATA%\com.recallmd.desktop\` 均不受安装影响）。
