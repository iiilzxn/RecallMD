## 相对 v0.3.0 的变化（复习题面简化：小节标题即题目）

### 题面统一为小节标题

- 复习与学习页的问题直接显示小节标题；无标题的文件前言块显示「回忆这篇笔记的前言内容」
- 移除独立的「题目目标」：不再在复习页编辑回忆目标（`review_set_prompt` 命令一并移除）；旧版本保存的题目目标不再显示和使用，数据库字段原地保留、不做迁移
- 路径面包屑不再重复题目本身（标题路径去掉最后一级）；题面字号加大并支持长标题任意断行

### 学习与评分流程更直接

- 「学习新内容」不再要求先保存题目目标，取到题目后直接阅读原文开始学习
- 队列只下发「是否已设得分点」标志（`hasRubric`），作答前不传任何答案标准，杜绝题面泄露
- 未设得分点的题目：仍可作答（含语音输入），但仅对照原文，不提交 Jev 评分；页面提示在笔记阅读视图标题旁的「＋」添加得分点后即可评分
- Jev 评分的题目固定取小节标题，不再受旧题目目标影响；「展开上下文正文」不触发评分

### 新用户引导

- 操作引导由 9 步收为 8 步（去掉「保存题目目标」一步）；旧版本引导停在该步的用户自动前进到「揭示」步

### 兼容性说明

- 无数据库迁移（schema 仍为 v2）；学习记录 / 得分点 / 语音与 Jev 设置 / 主题与引导偏好全部保留，覆盖安装升级
