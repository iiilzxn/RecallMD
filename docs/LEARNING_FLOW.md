# 明确题目目标与立即学习

## 使用流程

1. 在笔记中用独立的 Markdown 标题组织问题，例如「什么情况下需要回表？」；每个小节的直属正文作为答案。多个独立知识点请拆成多个小节，再点击「纳入复习」。
2. 打开侧栏「学习新内容」。未首次评分的新题可以当场学习，不必等待登记后的 24 小时。
3. 为题目保存一个明确的回忆目标。已有回忆提示直接沿用；没有目标时会先显示设置表单。标题本身就是问题时，可点击「用小节标题填写目标」，检查后保存。
4. 独立尝试回答，再揭示原文核对。还未学过时可以阅读理解后选 Again，进入短期巩固。评分以揭示前的回忆表现为准。
5. 首次评分后，该题进入 FSRS 学习或复习阶段。后续到期时从「今日待复习」继续；学习页提供切换按钮。

目标不会自动分析或拆分正文。一个块仍保存一份调度状态；如果答案包含多个可独立判断的知识点，应手动拆成多个标题小节。

## 调度与兼容性

- 沿用 `KnowledgeBlock.recall_prompt` 保存目标，无数据库格式迁移。原有目标、复习记录、FSRS 参数保持兼容。
- `learning_queue` 仅列出 ENABLED、ACTIVE、文件 PRESENT 且索引 READY、phase=NEW、first_review_at 为空的块，受新题日配额约束。
- `learning_begin` 签发带立即学习标志的进程内令牌。仅该令牌允许尚未首次评分的新题提前提交；普通复习的到期校验不变。
- 提交仍核验内容及状态版本、时钟、配额和幂等请求；首次评分后按实际评分时间推进 FSRS。
- 只打开、跳过或编辑目标不会提前到期，也不会消耗新题名额。未主动学习的新题仍按原规则在登记 24 小时后首次到期。
- 修改目标使旧令牌失效，并重新遮蔽答案。目标表单拒绝空白；评分前必须保存目标。

## 验证

- Rust：提前学习与普通到期守卫、目标变更令牌失效、首次评分及重试幂等、配额变更、不可用内容过滤、返回到期学习队列。
- TypeScript：学习/复习 IPC 路由分离、未来首次到期的新卡仍按实际学习时间正确调度，以及现有引擎与复习测试。
- 浏览器开发预览：`?demo=learning`；支持目标编辑、揭示、首次评分和新题队列更新。预览使用内存示例数据，真实存储由 Rust 集成测试验证。
