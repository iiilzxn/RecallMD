## 设计说明

- 统一采用浅色 Windows 桌面布局、细分隔线和青绿色强调色；复习保留知识库导航，让用户能随时回到原笔记。
- 编辑器保持 Markdown 源码，包括稳定身份注释；第三个“触发方式”知识块有自己的 ID。
- 回忆页的提示为可选的 recall_prompt 示例；显示上下文按钮处于未展开状态，不展示答案。
- RDB 的复习答案只包含两行直属正文；子标题“触发方式”的内容不重复混入 RDB。
- 编辑器示例表示首次登记当天，首次复习为明天；两张复习页表示其到期后的同一评分会话，尚未提交评分，所以剩余数保持 12。
- 评分间隔是视觉示例，开发时必须使用锁定的 Scheduler 返回值；不得从 PNG 抄写为固定算法。
- 这些是位图视觉稿。实际字号、对比度、尺寸自适应、键盘焦点、点击区域和长内容滚动仍需在实现阶段验证。
- 图片中文字和 ID 只用于视觉评审；文件格式、UUID 校验和交互行为以 PROJECT_DESIGN.md 为准。
