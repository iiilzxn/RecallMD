## 本轮设计说明

- 延续已有截图的窗口框架、知识库目录、浅色主题、青绿色强调色与中文排版。
- 统计数据为构造的视觉示例：每日次数 8/12/10/16/14/9/15 合计 84；四 Rating 次数 8/16/48/12 同样合计 84；复习过的不同知识块为 31。当前参与/暂停/排除为 156/8/6，合计 170。它们不是实际用户数据。
- 统计页保留每日柱形图，最终评分分布采用彩色圆点与次数，避免生成位图的条形长度影响数值解读；没有添加记忆率、排名或学习效果推断。
- 设置页包含本地知识库路径、自动保存、主题、新内容日上限、时区、元数据备份与完整知识库备份。备份开关是视觉提案，本轮未变更产品设计中的每日备份策略。
- 未新增“隐藏内部标记”设置：上一轮只是讨论候选方案，用户尚未要求修改这项交互。
- 冲突页并排展示本地未保存与磁盘版本，显示共同原文；突出“自动保存已暂停”和“本地草稿已保留”，提供使用磁盘版本、本地另存、手动合并。
- 冲突示例中的两份文件保留相同 Block ID。比较视图的注释换行仅为视觉折行，实际文件注释协议仍是单行。
- 使用磁盘版本前先保留本地恢复副本；另存副本要重新分配 Block ID；手动合并按钮进入合并流程，不能立即覆盖文件。具体行为遵循 PROJECT_DESIGN.md。
- 图中“Redis 是单线程的。”是待修订的共同原文示例，不应作为完整的 Redis 技术结论。
- 所有图仍是位图设计稿；实际布局响应、无障碍、焦点、滚动、图表比例与错误处理需在界面实现时验证。
