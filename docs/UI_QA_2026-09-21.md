# UI 与交互复查（2026-09-21）

本轮通过浏览器操作和模拟慢速/失败 IPC 的组件测试检查实际交互。新增测试先复现失败，再修复对应代码。

## 已修复

| 触发方式 | 复现的问题 | 修复 |
| --- | --- | --- |
| 快速依次打开 A、B，A 的读取较晚完成 | 界面被旧结果切回 A | 只采纳最新打开请求；关闭/切换知识库后忽略旧请求 |
| 打开另一篇笔记期间继续输入 | 后返回的正文覆盖未保存内容 | 替换前再次检查保存状态，通过既有保存/放弃/取消流程处理 |
| 新文件读取失败 | 已打开的笔记被关闭 | 保留当前文件与修改，显示失败提示 |
| 恢复草稿读取失败 | 有效正文也被当成打开失败而关闭 | 正文打开与可选草稿读取分别处理 |
| 文件读取期间转到统计页 | 读取完成又强行跳回编辑页 | 后返回的数据不再改变用户已选择的页面 |
| 阅读小文件后打开超过预览上限的大文件 | 仍尝试渲染大文件，编辑按钮也被禁用 | 立即回到编辑视图，禁用的仅是阅读预览 |
| 编辑器获得输入焦点时按 Ctrl+E | 快捷键被输入框保护误拦截 | 允许编辑器内切换，仍保护搜索框和对话框 |
| 评级按钮获得焦点时按 1–4 | 数字快捷键失效 | 仅为空格保留按钮默认行为；组合键与连发不触发评级 |
| 标题旁悬浮查看 500 字得分点 | 提示框底部超出窗口约 53 px | 根据实际尺寸与可用空间定位，长内容可在框内滚动 |
| 填写得分点时原文被外部更新 | 弹窗自动关闭，输入消失 | 保留输入并提示原文已变化，阻止向旧题面保存或删除 |

## 验证结果

- 新增 14 项回归检查，覆盖文件切换、未保存输入、读取失败、大文件视图、快捷键、得分点草稿与提示框边界。
- `pnpm typecheck` 通过。
- `pnpm test`：26 个文件，214 项通过，2 项既有测试跳过。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib --tests`：89 项通过；3 项真实 Jev 调用和 2 项性能测试按配置跳过。
- `pnpm build` 通过。原有包体积提示、Rust 未使用代码提示仍存在，不影响构建。
- 浏览器复测：长提示完整文本为 500 字，边界位于窗口内；能滚动到底且不消失。编辑器中 Ctrl+E 能进入阅读；焦点在 Again 按钮时按 3，会正确提交 Good 并进入下一题。

组件测试使用 `happy-dom` 作为开发依赖，保留实际应用状态逻辑和 SaveCoordinator，只模拟宿主 IPC、编辑器显示和工作线程。没有对用户的真实知识库进行测试写入，也没有再次调用付费 Jev 接口。
