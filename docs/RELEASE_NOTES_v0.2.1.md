## 相对 v0.2.0 的变化（UI 精修：交互与可用性）

### 导航与对话框

- 显式四页导航：侧栏固定「笔记 / 今日待复习 / 统计 / 设置」入口，重复点击幂等；从任何页面打开文件都回到编辑器（未保存守卫行为不变）
- 模态对话框全部改为原生 `<dialog>`：焦点陷阱、关闭后焦点还原；可取消的对话框支持 Esc 关闭，保存冲突与草稿决策仍需显式选择；对话框打开期间应用快捷键（Ctrl+P / Ctrl+E / 复习键）不再误触，支持对话框堆叠

### 设置页

- 新增「复习内容管理」：查看已暂停 / 已排除的内容（支持按标题或路径搜索、分批加载），一键恢复复习 / 重新纳入；走既有 RESUME / INCLUDE 命令，学习进度保留，不重置历史、不改动调度
- 每日新内容上限改为显式「保存上限」按钮 + 「尚未保存」指示；即时生效的设置标注「更改后立即生效」
- 状态栏保存反馈对齐实际配置：区分「等待自动保存」与「请按 Ctrl+S 保存」
- 调度算法参数等技术细节折叠为渐进披露

### 复习页

- 跳过仍为一级操作；「暂停复习」「排除此内容」移入「更多操作」次级折叠区
- 排除需二次确认，说明笔记正文与学习进度保留，并指明恢复路径（设置 → 复习内容管理）
- 评分按钮主文案改为中文提示语；阶段标签（新内容 / 学习中 / 复习中 / 重新学习中）本地化

### 视觉与可达性

- 统一 SVG 图标库（跟随主题换色），替代 emoji / 字符图标；文件操作按钮不再遮挡文件名
- 侧栏分区重排（工作区标识、文件操作、过滤、导航分层），低频工具视觉降级
- 文档目录条目改为原生按钮；图标控件补齐 aria 标签；通知 / 错误带 role；紧凑宽度下全部入口可达（目录移至编辑区下方）
- 启动屏与空状态重写

### 兼容性说明

无持久化格式、FSRS 调度、Rust 代码与依赖变更。开发用浏览器 stub 增强了示例数据与参与状态模拟（可演示暂停 → 恢复闭环），不进入生产构建。

## 安装与升级

同 v0.1.x / v0.2.0：直接安装覆盖，学习记录 / 最近列表 / 主题偏好均保留；卸载不动知识库。
