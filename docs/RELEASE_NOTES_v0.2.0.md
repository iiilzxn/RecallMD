## 相对 v0.1.1 的变化（M9：扩展渲染与主题）

### 新增

- **Mermaid 图表**：` ```mermaid ` 围栏渲染为图表，编辑预览与复习页同时生效；按需加载（无图表零开销）；语法错误回退显示源码与错误信息；跟随主题重绘
- **本地图片显示**：工作区相对路径图片与 `data:image` 内联图片正常显示（Tauri asset 协议，仅限当前打开的知识库目录，无网络请求）；远程 http(s) 图片仍为占位框（离线原则）
- **预览/复习代码高亮**：常用语言子集着色（highlight.js，按需加载）；与编辑器同一套配色令牌
- **`==高亮==` 语法**：Obsidian 风格记号笔高亮
- **脚注与锚点跳转**：脚注按引用顺序编号、点击跳到文末定义、定义带回链；文内 `#锚点` 链接可点跳转（GitHub 风格 slug）；复习片段自动携带全文中的引用/脚注定义（顺带修复了 v0.1.1 起复习片段里引用式链接显示为字面文本的问题）
- **受限 HTML 白名单**：`<sub>`/`<sup>`/`<kbd>`/`<br>` 与可折叠 `<details>/<summary>` 正常呈现（其余原始 HTML 照旧不执行；此前 `<details>` 整块内容在预览中不可见）
- **深色模式**：设置 → 外观 → 跟随系统 / 浅色 / 深色；全应用换肤（编辑器、预览、图表、复习），偏好即时保存

### 安全模型说明（设计 §161 修订）

白名单 HTML 反解析为受控元素，仍无任意 HTML 执行路径；Mermaid 输出经 mermaid strict 内部消毒 + DOMPurify 白名单二次消毒后注入（全仓库唯一 HTML 注入点位）；本地图片经 asset 协议且范围限定激活工作区。

### 已知取舍

- LaTeX 公式本版不含（按需求明确排除）
- 远程图片不自动加载（保持离线原则）
- 外链仍需手动复制到浏览器打开

## 安装与升级

同 v0.1.x：直接安装覆盖，学习记录/最近列表/主题偏好均保留；卸载不动知识库。
