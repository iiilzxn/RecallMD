## 相对 v0.2.1 的变化（学习体验：智能打分、语音输入、引导与全新视觉）

### Jev 智能打分（可选，云端）

- 笔记预览的小节标题旁可维护得分点：每点最多 500 字、每小节最多 30 点，以稳定 block ID 存入新增的 `ReviewRubric` 表（schema v2，沿用迁移前备份机制）
- 「设置 → Jev 智能打分」填入 TypeSafe API Key（存 Windows 凭据管理器，界面不回显密钥）
- 复习页提交答案后逐点返回 0/1/2 覆盖等级、置信度与百分制总分；置信度低于 0.6 的得分点标记「待核对」并暂缓展示总分
- Jev 不决定复习间隔，不自动提交 FSRS 评级；仅发送本题题目、得分点与提交的答案，不上传笔记全文

### 本地离线语音输入

- 复习页「语音回答」或 F2 开始录音，再按 F2 结束并离线转写为中英文本，追加到已有答案后自行提交评分
- 唯一支持模型：Paraformer 中英双语 FP32（encoder.onnx / decoder.onnx / tokens.txt，约 825 MiB）。模型不随安装包分发，需放置于 `%LOCALAPPDATA%\com.recallmd.desktop\speech-models\` 或在设置页指定模型目录
- 安装包新增 4 个原生运行时 DLL（ONNX Runtime 与 sherpa-onnx C/C++ API）；推理纯本地 CPU，音频只在内存处理，不写录音文件、不上传语音
- 「设置 → 语音输入」提供模型状态、麦克风选择、3 / 10 / 30 分钟录音上限与「试录一段」

### 学习流程：明确目标与立即学习

- 侧栏新增「学习新内容」：未首次评分的新题可当场学习并评分，不必等待登记 24 小时；后续到期进入「今日待复习」
- 题目可保存明确的回忆目标（沿用 `recall_prompt`，无数据库迁移）；修改目标使旧复习令牌失效并重新遮蔽答案

### 新用户引导

- 首次使用显示四页概念图，再沿真实界面高亮完成 9 步操作引导（打开知识库 → 新建笔记 → 纳入复习 → 得分点 → 学习 → 保存目标 → 揭示 → 评级）
- 可跳过、暂停、收起提醒；启动页 / 侧栏 / 设置提供重新打开入口；不自动创建笔记、不自动评级

### UI「书房」重设计与新图标

- 暖纸色阅读界面与深色界面（苔绿强调），统一按钮 / 对话框 / 输入框 / 反馈与空态；Mermaid 跟随主题取色
- 各页重排：启动页双栏欢迎、笔记编辑/阅读双按钮切换、复习页「先回忆 / 后对照」两段式与本轮进度、统计页真实复习次数与今天/近 7 天/近 30 天自评分布、设置页分组与主题可视预览
- 新应用图标 v2：苔绿圆角方块与展开书页，覆盖 EXE 图标、侧栏与浏览器页签

### 兼容性说明

- 数据库升级至 schema v2（新增得分点表），自动迁移并保留原有题目目标与学习进度
- 语音模型需单独获取（见 `docs/LOCAL_SPEECH.md`）；Jev 需自备 API Key 且默认关闭——两者均不影响原有复习功能
- 覆盖安装升级，学习记录 / 最近列表 / 主题偏好保留；卸载不动知识库
