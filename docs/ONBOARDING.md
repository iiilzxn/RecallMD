# 新用户引导

首次使用显示四页概念图：本地 Markdown 知识库、小节与题目、得分点、主动回忆与间隔复习。插图由 HTML、SVG 图标和 CSS 绘制，跟随明暗主题，无远程素材依赖。

操作引导沿真实界面高亮 9 个步骤：打开知识库 → 打开或新建笔记 → 纳入复习 → 阅读预览 → 得分点（可跳过）→ 学习新内容 → 保存题目目标 → 揭示原文 → 选择评级。

- 按实际应用状态和保存成功回调推进。取消弹窗、保存失败、跳过题目都不视作评级成功。
- 不自动创建或替换笔记，不自动评级，也不要求开启 Jev。空白且可编辑的笔记可由用户主动点击「填入示例」。保存和纳入继续使用现有编辑协调器。
- 原生模态弹窗打开期间，操作提示让出界面；关闭后恢复。提示本身不封锁应用操作。定位随滚动、窗口大小和界面变化更新。
- 可以跳过概念页、暂停引导、收起提醒。启动页、侧栏和「设置 → 新手引导」提供重新打开入口；设置还可以继续上次进度或重新开始。
- 本设备的 `localStorage` 键 `recallmd.onboarding.v1` 只记录概念页是否已看过、引导状态和步骤，不存笔记内容或凭据。存储不可用时，本次会话仍可正常引导。
- 队列为空时提示可能的原因，并提供今日复习和结束入口。重新打开软件/切换知识库后，需要先打开知识库或笔记才能继续对应步骤。

验证：`pnpm typecheck`、`pnpm test`、`pnpm build`。自动化测试覆盖首次展示与跳过持久化、暂停恢复、失败不推进、队列为空、偏好损坏，以及示例不替换已有笔记。浏览器验证空白知识库到首次评级的完整流程、原生 dialog 让位、明暗主题和 960×600 最小桌面窗口。

开发预览：`pnpm dev --host 127.0.0.1`，访问 `http://127.0.0.1:5173/?demo=onboarding`。该模式提供内存中的空知识库，刷新即清除演示笔记与学习记录。只在开发服务器注入，真实 Tauri 和生产构建不使用此模拟宿主；引导偏好仍按正常方式保存，可从界面重新打开。
